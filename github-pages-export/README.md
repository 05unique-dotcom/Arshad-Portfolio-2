# GitHub Pages Export

This folder is generated by:

```bash
bun scripts/export-github-pages.mjs
```

It contains a fully static version of the portfolio (`index.html` + assets)
that works on GitHub Pages — both for a user site (`<user>.github.io`) and a
project site (`<user>.github.io/<repo>/`).

## Deploy steps

1. Run `bun scripts/export-github-pages.mjs`.
2. Copy **everything inside** `github-pages-export/` (including the hidden
   `.nojekyll` file) to the **root of the GitHub repository** you use for
   Pages — `index.html` must sit at the repository root.
3. Commit and push.
4. In the repo on GitHub: **Settings → Pages → Source → Deploy from a branch**,
   pick the branch you pushed and the `/ (root)` folder.
5. Wait a minute — your site is live at the URL GitHub shows there.

Re-run the script whenever you change the site, then copy and push again.
